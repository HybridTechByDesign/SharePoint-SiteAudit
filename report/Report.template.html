How to avoid this

This isn't a fault in SharePoint or OneDrive. It happens when whole folder trees are copied in. These four habits keep it from coming back.

  1. Bring files, not folder trees.When you get files from another team, copy the files you need into our folder. Don't drag their whole folder structure across.
  2. Skip the desktop step.Upload straight into SharePoint in the browser, or ask for a shared link. Saving to the desktop first and then moving it all in is where deep folders come from.
  3. Don't repeat the client name.The client folder already says who it's for. Leave the client name out of sub-folder and file names.
  4. No more than 3 folder levels below the section folder.If you need a fourth level, it's usually a sign that something was copied in as a whole tree.
